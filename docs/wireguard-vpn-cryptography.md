# WireGuard Protocol & Cryptokey Routing

Noise protocol framework, Curve25519, ChaCha20-Poly1305, and BLAKE2s.

## Overview
Technical cheat sheet for `wireguard-vpn-cryptography` covering production deployment, configuration, and diagnostics.

## Commands and Usage
```bash
wg show
wg set wg0 peer <pubkey> allowed-ips 10.0.0.2/32
```
